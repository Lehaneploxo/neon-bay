- Жизнь на улицах: тележки с хот-догами и мороженым (лечат), уличные музыканты с саксофоном, гитарой и вёдрами-барабанами (своя музыка, можно дать чаевые), серферы на волнах у пляжа Санрайз и пляжный волейбол

## Управление
**Компьютер:** WASD — ходьба, мышь — камера, Shift — бег, пробел — прыжок, F — сесть/выйти из машины, R — следующая радиостанция, ЛКМ — удар/выстрел, ПКМ — прицел, Q или 1–6 — сменить оружие, Tab — карта, M — звук, Esc — пауза.

**Телефон:** левый палец — джойстик, правый — камера, кнопки справа — действия, нажатие на мини-карту — вся карта. Лучше держать телефон горизонтально.

Работает в любом современном браузере, нужен интернет (3D-движок three.js грузится с CDN).

## Сервер
Папка `server/` — отдельный сервис `neploxo-server` на Railway (https://neploxo-server-production.up.railway.app), не связан с сервером TikTok-игр. Хранит аккаунты и сохранения в Postgres (таблицы `gta_*`) и отдаёт общее время. Пересобирается только когда меняется `server/`; обновления игры (index.html, js/) выходят как раньше — пушем в main.

Локально: `cd server && npm install && node server.js` (порт 3100, без `DATABASE_URL` данные в `server/.dev_db.json`), игра на localhost сама ходит на этот порт.
